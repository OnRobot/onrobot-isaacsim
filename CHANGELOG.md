# Changelog

## v1.1.0

This release updates the existing assets for SimReady and Isaac Sim 6.1.

* Record an interface revision for each model alongside its SimReady package version. ROS can then use compatible asset updates without a new ROS release.
* Support Isaac Sim 6.1.
* Package each gripper with metadata and thumbnails; entry points are now `assets/onrobot_<model>/simready_usd/onrobot_<model>.usda`.
* Include NVIDIA's bill of materials and validation and benchmark reports in each model package.
